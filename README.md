# Plato

A runnable static prototype of the multi-role education and community platform described in the supplied build specification and styled around the Credential design showcase.

## Run locally

Open `index.html` directly, or serve the repository with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Public landing page and six-step join wizard
- Student, Representative Student, Teacher, Manager, and Admin role views
- Active-course context and populated course/subject data
- Signup approval and rejection interactions
- Admin impersonation demo
- Credential-inspired glass, brass, aqua, seal, motion, and responsive design
- Local mock data only; no backend or deployment infrastructure

The original visual reference remains in `credential-showcase.html`.
